# 3. Demo Video Script (2 Minutes)

### Context
This script is for a screen-recorded product demo video that will be shared primarily on WhatsApp (sent by field sales reps) and social media (Instagram Reels, TikTok, Facebook). The video must be compelling in the first 5 seconds, work with or without sound (text overlays), and end with a clear CTA. Screen recordings should be done on a phone to match the audience's device context.

---

## Technical Specs
- **Duration:** 2:00 exactly
- **Format:** Vertical (9:16) for mobile-first — can be adapted to horizontal for website
- **Resolution:** 1080x1920 minimum
- **Music:** Upbeat Afrobeats instrumental — energetic but not distracting. Volume dips under voiceover, rises during transitions.
- **Pace:** Quick cuts, no dead air. Every second earns the next second of attention.
- **Captions:** Hardcoded English subtitles throughout (many viewers watch without sound)

## Usage Notes

- **WhatsApp sharing:** Export as MP4, keep file size under 16MB for easy WhatsApp forwarding. Vertical format (9:16) is essential — horizontal videos get scrolled past on WhatsApp Status and mobile feeds.
- **Social media adaptations:**
  - **Instagram Reels / TikTok:** Use as-is (vertical). Add trending audio if appropriate but keep voiceover as primary.
  - **Facebook:** Can be posted as both vertical video (for mobile feed) and adapted to 1:1 square for desktop.
  - **Website:** Create a 16:9 horizontal version using the same script and recordings for the landing page hero section.
- **Localization:** Record versions in Twi and Ga for targeted campaigns in specific regions. The script structure stays the same — just translate the voiceover.
- **A/B test the hook:** Try an alternate opening — start with the loss prevention alert ("Your cashier just voided a GHS 450 sale...") instead of the book/calculator scene. Test which gets more completions.
- **Screen recording tips:** Use a real demo account loaded with realistic Ghanaian product names and prices. Don't use placeholder data. Record at 60fps for smooth scrolling. Zoom in on key UI elements.
- **Voice talent:** Use a Ghanaian English speaker with a warm, confident tone — not a radio announcer voice. Should sound like a knowledgeable friend, not a salesperson.
